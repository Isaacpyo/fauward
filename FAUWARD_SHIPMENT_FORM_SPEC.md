# Fauward Shipment Creation Form Spec

Read-only audit of `apps/widget/components/shipments/CreateShipmentForm.tsx`, its widget routes, tenant/token helpers, and shipment schemas.

## Sources Read

- `@fauward/tenant-db` has no `schema.prisma`; its package exports TypeScript source from `packages/tenant-db/src/index.ts` via `package.json` and contains `src/schema.ts`, `src/queries/shipments.ts`, and `src/queries/tenants.ts` instead (`packages/tenant-db/package.json:1`, `packages/tenant-db/package.json:9`, `packages/tenant-db/src/schema.ts:8`, `packages/tenant-db/src/queries/shipments.ts:15`).
- The canonical Prisma schema read for platform models is `apps/backend/prisma/schema.prisma`; it defines PostgreSQL datasource settings (`apps/backend/prisma/schema.prisma:7`) and the shipment-related models cited below.
- The actual widget write target is the per-tenant Supabase schema: `getTenantDb(slug)` uses `db: { schema: tenantSchema(slug) }`, and `tenantSchema` maps slugs to `tenant_<slug>` with hyphens replaced by underscores (`packages/tenant-db/src/client.ts:57`, `packages/tenant-db/src/client.ts:61`, `packages/tenant-db/src/client.ts:73`).
- The per-tenant table template is loaded from `supabase/migrations/0002_tenant_schema_template.sql` by `packages/tenant-db/src/schema.ts` (`packages/tenant-db/src/schema.ts:8`, `packages/tenant-db/src/schema.ts:10`, `packages/tenant-db/src/schema.ts:24`).
